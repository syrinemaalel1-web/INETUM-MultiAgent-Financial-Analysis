Ce fichier contient la commande (prompt) complète pour générer le fichier
agents.py du pipeline CMF Tunisie avec CrewAI.

Principes directeurs :
  [1] Anti-hallucination absolute : si une donnée est absente du rapport,
      l'agent écrit "DONNÉE MANQUANTE" — il n'invente JAMAIS une valeur.
  [2] Unité financière forcée : toutes les valeurs sont en Dinar Tunisien (DT).
      L'agent vérifie l'unité dans le rapport (DT, MDT, KDTE) et convertit
      explicitement avant tout calcul.
  [3] Normes SCE Tunisie : les formules suivent le Système Comptable des
      Entreprises tunisien, pas les normes IFRS ou françaises.
  [4] Chaîne de confiance : l'agent Rapporteur ne rédige JAMAIS une section
      si l'agent Calculateur a retourné "DONNÉE MANQUANTE" pour les inputs
      de cette section — il signale l'absence au lieu d'improviser.

IV. TASK 1 — EXTRACTION ET CALCUL DES KPI (Anti-hallucination)
════════════════════════════════════════════════════════

Crée une Task CrewAI avec la description suivante (utilise une f-string
pour injecter le contenu du rapport Markdown via une variable `rapport_md`) :

  description = f"""
  Tu reçois un rapport financier tunisien au format Markdown :

  ===RAPPORT SOURCE===
  {rapport_md}
  ===FIN DU RAPPORT===

  ÉTAPE 1 — VÉRIFICATION DE L'UNITÉ MONÉTAIRE
  Avant tout calcul, identifie l'unité utilisée dans le rapport :
  - DT (Dinars Tunisiens réels)
  - MDT ou KDTE (Milliers de Dinars Tunisiens) → multiplier par 1 000
  - MDT (Millions de DT) → multiplier par 1 000 000
  Indique explicitement l'unité détectée et le facteur de conversion appliqué.
  Si l'unité est ambiguë, écris 'UNITÉ AMBIGUË — valeurs brutes conservées'.

  ÉTAPE 2 — EXTRACTION DES RUBRIQUES SCE
  Extrais les valeurs suivantes depuis le rapport source.
  Pour chaque rubrique introuvable, écris 'DONNÉE MANQUANTE'.
  Ne devine jamais. Ne calcule pas par déduction si la valeur n'est pas
  explicitement dans le document.

  RUBRIQUES À EXTRAIRE :
  [BILAN — ACTIF]
    A1 : Total Actif Non Courant
    A2 : Actifs Courants (hors trésorerie)
    A3 : Trésorerie Actif (disponibilités + équivalents)
    A4 : Total Actif (= A1 + A2 + A3)

  [BILAN — PASSIF]
    P1 : Capitaux Propres
    P2 : Dettes Non Courantes (emprunts LT, provisions LT)
    P3 : Passifs Courants (hors trésorerie passif)
    P4 : Trésorerie Passif (concours bancaires CT)
    P5 : Total Passif (= P1 + P2 + P3 + P4)

  [ÉTAT DE RÉSULTAT]
    R1 : Chiffre d'Affaires (Revenus d'exploitation)
    R2 : Résultat d'Exploitation (EBIT)
    R3 : Résultat Net de l'exercice

  ÉTAPE 3 — CALCUL DES KPI SCE TUNISIE
  Calcule chaque KPI UNIQUEMENT si toutes ses composantes sont disponibles.
  Sinon, écris 'KPI NON CALCULABLE — [liste des données manquantes]'.
  Montre le calcul détaillé étape par étape. Arrondis à 2 décimales.

  KPI DE RENTABILITÉ :
    KPI_R1 : Marge d'Exploitation (%) = (R2 / R1) × 100
    KPI_R2 : Marge Nette (%) = (R3 / R1) × 100
    KPI_R3 : ROE (%) = (R3 / P1) × 100
    KPI_R4 : ROA (%) = (R3 / A4) × 100

  KPI DE STRUCTURE FINANCIÈRE :
    KPI_S1 : Autonomie Financière (%) = (P1 / A4) × 100
              → Seuil sain : > 30%
    KPI_S2 : Ratio d'Endettement = (P2 + P3 + P4) / P1
              → Seuil acceptable : < 1.0
    KPI_S3 : Capitaux Permanents = P1 + P2
    KPI_S4 : Fonds de Roulement Net Global (FRNG) en DT = KPI_S3 - A1
              → Positif = bonne structure ; Négatif = déséquilibre
    KPI_S5 : BFR en DT = A2 - P3
              → Positif = besoin à financer ; Négatif = ressource
    KPI_S6 : Trésorerie Nette (TN) en DT = KPI_S4 - KPI_S5
              Vérification : TN = A3 - P4

  KPI DE LIQUIDITÉ :
    KPI_L1 : Liquidité Générale = (A2 + A3) / (P3 + P4)
              → Seuil correct : > 1.0
    KPI_L2 : Liquidité Immédiate = A3 / (P3 + P4)
              → Seuil prudent : > 0.2

  ÉTAPE 4 — TABLEAU RÉCAPITULATIF
  Retourne un tableau Markdown structuré avec :
  | KPI | Formule SCE | Valeur (DT ou %) | Seuil Référence | Statut |

  RÈGLE FINALE ABSOLUE :
  Si tu n'es pas certain d'une valeur, écris 'DONNÉE MANQUANTE'.
  Il vaut mieux un rapport incomplet et honnête qu'un rapport complet et faux.
  """

  expected_output = """
  Un tableau Markdown structuré contenant :
  1. L'unité détectée et le facteur de conversion
  2. Toutes les rubriques extraites (avec 'DONNÉE MANQUANTE' si absent)
  3. Tous les KPI calculés (avec 'KPI NON CALCULABLE' si données absentes)
  4. Le détail de chaque calcul
  5. Le tableau récapitulatif final
  Toutes les valeurs absolues sont en Dinar Tunisien (DT).
  """

VI. CREW ET FONCTION D'ENTRÉE
════════════════════════════════════════════════════════

Crée un Crew avec :
  agents = [agent_calculateur, agent_rapporteur]
  tasks = [task_calcul, task_rapport]
  process = Process.sequential
  verbose = True
  memory = False  # Pas de mémoire inter-session pour éviter la contamination

Crée une fonction principale :

  def analyser_rapport(rapport_md: str, output_path: Path = None) -> str:
      """
      Lance le pipeline CrewAI complet sur un rapport financier Markdown.

      Args:
          rapport_md : Contenu Markdown du rapport extrait par extract.py
          output_path : Si fourni, sauvegarde le rapport final en .md

      Returns:
          str : Le rapport d'analyse financière en Markdown
      """
      # Injecter le rapport dans la task_calcul
      task_calcul.description = task_calcul.description.replace(
          "{rapport_md}", rapport_md
      )
      result = crew.kickoff()
      rapport_final = result.raw

      if output_path:
          output_path.parent.mkdir(parents=True, exist_ok=True)
          output_path.write_text(rapport_final, encoding="utf-8")
          print(f"✅ Rapport sauvegardé : {output_path}")

      return rapport_final


  if __name__ == "__main__":
      import argparse
      parser = argparse.ArgumentParser(description="Agents CMF Tunisie — Analyse KPI SCE")
      parser.add_argument("--input", type=Path, required=True,
                          help="Fichier Markdown extrait (sortie de extract.py)")
      parser.add_argument("--output", type=Path, default=None,
                          help="Fichier Markdown de sortie du rapport")
      args = parser.parse_args()

      rapport_md = args.input.read_text(encoding="utf-8")
      analyser_rapport(rapport_md, args.output)
